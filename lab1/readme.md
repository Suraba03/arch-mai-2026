## Выбранный вариант: Сервис доставки (аналог CDEK)
Источник: https://www.cdek.ru/ru/

### Хранимые данные
- Пользователь
- Посылка
- Доставка

### Реализуемое API
- Создание нового пользователя
- Поиск пользователя по логину
- Поиск пользователя по маске имени и фамилии
- Создание посылки
- Получение посылок пользователя
- Создание доставки от пользователя к пользователю
- Получение информации о доставке по получателю
- Получение информации о доставке по отправителю

### Роли пользователей
- **Клиент (отправитель)** — создаёт посылки и доставки.
- **Получатель** — получает уведомления и отслеживает доставку.

### Внешние системы
- **Платёжный шлюз** (ЮKassa) — оплата доставки.
- **SMS-сервис** — уведомления о статусе.
- **Email-сервис** — уведомления о статусе.
- **Сервис геокодирования** (Yandex Maps / 2GIS) — расчёт маршрута и стоимости.

## Описание диаграмм

### C1 - System Context
Показывает место `CDEK Service` в окружении: с системой взаимодействуют две роли (Клиент и Получатель), а сама система обращается к четырём внешним сервисам — платёжному шлюзу, SMS-, email- и геокодинг-сервисам.

### C2 — Containers
Раскрывает внутреннее устройство сервиса:
- **Web / Mobile Application** — клиентские приложения.
- **API Gateway** — единая точка входа, маршрутизация и аутентификация.
- **User Service / Parcel Service / Delivery Service** — доменные сервисы по сущностям задания.
- **Notification Service** — рассылка уведомлений по событиям из брокера.
- **PostgreSQL** — основное хранилище.
- **Redis** — кеш поиска пользователей.
- **Kafka** — асинхронные события (`DeliveryCreated`, `ParcelCreated`).

Синхронные вызовы — gRPC между сервисами и REST/HTTPS на границах; асинхронные события идут через Kafka.

### Dynamic — «Создание доставки»
Архитектурно значимый сценарий: отправитель создаёт доставку получателю.
Поток: Web → API Gateway → Delivery Service, который проверяет получателя в User Service, забирает посылку из Parcel Service, считает маршрут через геокодинг, сохраняет доставку в БД и публикует событие `DeliveryCreated`. Notification Service по событию рассылает SMS и email получателю.
